2. style.css (Стиль «Premium IT») Этот CSS делает всё «красивым» за счет теней, закруглений и шрифтов. * { box-sizing: border-box; } body { font-family: 'Inter', sans-serif; background: #f0f2f5; margin: 0; display: flex; justify-content: center; padding: 40px 20px; } .main-wrapper { width: 100%; max-width: 600px; } header { text-align: center; margin-bottom: 40px; } h1 { font-size: 2.5rem; margin: 0; color: #1a1a1a; } .subtitle { color: #666; font-size: 1.2rem; margin-top: 5px; } .card { background: white; padding: 30px; border-radius: 20px; box-shadow: 0 10px 30px rgba(0,0,0,0.05); margin-bottom: 20px; } h2 { font-size: 1.2rem; color: #0070f3; margin-top: 0; } .project-list { list-style: none; padding: 0; } .project-list li { background: #f8f9fa; padding: 12px; border-radius: 10px; margin-bottom: 10px; } .btn { display: block; text-align: center; background: #0070f3; color: white; padding: 15px; border-radius: 12px; text-decoration: none; font-weight: bold; margin-top: 20px; transition: 0.3s; } .btn:hover { background: #0051ad; transform: translateY(-2px); } Почему это сработает: 1. Шрифт Inter: Это шрифт, на котором написаны все современные интерфейсы (его используют Notion, Figma, GitHub). С ним всё сразу выглядит «дороже». 2. Карточки с border-radius: 20px: Скругленные углы и мягкая тень (box-shadow) делают сайт «объемным» и современным. 3. Отступы: Много свободного места вокруг блоков — это признак хорошего дизайна. Что делать: 1. Замени код в обоих файлах. 2. Сделай git push. 3. Забудь про Ctrl+F5 и просто открой сайт через минуту. Если это не выглядит «красиво», значит, мы с тобой по-разному понимаем «красоту» (например, тебе может нравится неоновый киберпанк или что-то очень темное). Если хочешь другой стиль (например, темную тему, или наоборот — что-то очень яркое) — скажи, я подберу палитру!
